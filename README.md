# FinTrack

A full-stack expense tracking web application built using React, Node.js, Express, and MongoDB Atlas.

## Live Demo

Frontend:
https://fintrack-adnan.vercel.app

Backend:
https://fintrack-backend-srjv.onrender.com

---

## Features

- Add expenses
- Delete expenses
- Categorize spending
- Track Needs / Wants / Savings
- 50/30/20 budgeting overview
- Persistent cloud database storage
- Responsive modern UI
- Full-stack deployment

---

## Tech Stack

### Frontend
- React
- Vite
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

### Deployment
- Vercel (Frontend)
- Render (Backend)
